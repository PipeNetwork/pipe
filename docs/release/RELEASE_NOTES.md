Pipe CLI 3.0.0-rc.3 adds durable storage buckets, scoped application keys, indexed search, CORS configuration, signed webhooks, and previewed lifecycle expiration. `pipe storage` manages these workflows, and `pipe s3 setup --write --bucket NAME` connects a managed bucket for familiar `ls`, `cp`, `mv`, `rm`, and `sync` operations. Unknown creation outcomes retain their original request IDs and encrypted recovery records.

The matching console includes first-upload setup, persistent transfer receipts, global file search, team access, bucket settings, and object-storage spending caps. Secrets require explicit export and are saved securely before activation. Existing shared namespaces, billing ownership, PIPEENC2 ciphertext, and payment recovery journals are preserved.

The release includes Linux x86-64/ARM64, macOS x86-64/ARM64, and Windows x86-64 binaries, checksums, installers, and GitHub Actions provenance. Use the [verification instructions](https://github.com/PipeNetwork/pipe/blob/v3.0.0-rc.3/docs/release/VERIFY.md), [migration guide](https://github.com/PipeNetwork/pipe/blob/v3.0.0-rc.3/docs/release/MIGRATION.md), and [storage workflow guide](https://github.com/PipeNetwork/pipe/blob/v3.0.0-rc.3/docs/storage-bucket-automation.md). Attached qualification records identify the tested source, deployed backend revisions, immutable contracts, production checks, and cleanup.

The production object limit remains 18 GiB. Bucket deletion, email delivery of invitations, public KV creation, and general CLI admission remain outside this release's enabled scope. Canonical Google-account team acceptance still needs an authorized production test account; team roles and isolation are exercised against real PostgreSQL fixtures and browser tests. Aged lifecycle expiration is qualified with staging fixtures; production qualification covers preview, enable/disable, and stale-version protection.

The persistent testing-credit ceiling is $1,000 across all campaigns and reruns. Outstanding reservations count toward that ceiling. No automatic funding or real payment transfers are part of this qualification. This is a release candidate; it does not promote the whole platform to general availability.
