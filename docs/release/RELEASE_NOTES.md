Pipe CLI 3.0.0-rc.2 gives S3 failures explicit error codes and exit statuses for automation. Versioned JSON and JSONL errors include `http_status` and `s3_code`, and streaming upload errors retain the server's rejection details. Submitted mutations with an uncertain outcome retain exit status `8`, including when a later retry receives a definitive refusal. Error messages omit request URLs and unrelated internal causes.

The release pipeline qualifies Linux x86-64/ARM64, macOS x86-64/ARM64, and Windows x86-64 archives, installers, upgrade/rollback checks, and GitHub Actions provenance.
